How rodseo chat texts you first

An AI can't start a chat by itself, so rodseo chat runs the timer for it. When the timer fires, rodseo chat asks your AI to write the next text using your instructions and the recent chat, then shows it here and sends a notification. Your replies go to the same AI. This all runs in your browser, so keep the tab open.
